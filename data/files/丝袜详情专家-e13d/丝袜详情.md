# 丝袜B端四张采购详情图

## 唯一受众

本技能只服务品牌采购商、进口商、批发商、零售商买手和private label客户，目标是降低技术核验、定制沟通和供应评估成本。

不得输出跨境C端内容：爆品标题、社媒钩子、消费者情绪文案、穿搭氛围、显瘦叙事、个人购买CTA或零售退换政策。用户需要C端六图与标题时使用 `hosiery-cross-border-c-end-six-images`。

## 输入预检

收集：

1. 产品规格：品类、D数、成分、尺码、颜色、腰头、裆型、腿部、袜头/袜跟结构。
2. 技术证据：针数、压力、回弹、耐磨、防勾丝、透气、保暖等测试条件、标准、结果和报告。
3. 定制范围：颜色、Logo、腰卡、吊牌、包装、尺码、配方或结构限制。
4. 商务条件：MOQ、样品政策、打样周期、交期、产能和付款/贸易条件（仅用户要求时）。
5. 供应证据：工厂、设备、生产流程、质检节点、仓库、包装、认证和审厂资料。
6. 素材：产品全貌、五区微距、测试照片、技术图纸、工厂/仓库/包装/证书原件。

提到有图片但当前消息无附件、文件或可访问URL时，视为图片缺失；不得搜索其他素材代替或臆测产品事实。

## 证据门

- A级：用户确认的规格、技术报告、证书、商务和供应数据。
- B级：从已读取清晰原图直接可见的外观和结构。
- C级：尚无证据的参数、功能、认证、定制或供应能力。

只有A级/B级可进入英文图片文案、数据卡和提示词。C级只进入中文补料动作，不得预写英文采购卖点。

禁止跳推：

- 15D或含氨纶不证明柔软、高回弹、防勾丝或不变形。
- T裆不证明无缝、平缝、透气或隐形。
- 加固袜头不证明具体耐磨次数或使用寿命。
- 有颜色/包装定制不等于支持Logo、private label或全套OEM/ODM。
- 有工厂照片不等于某个产能、交期或质量体系。
- 证书图标不等于证书覆盖当前产品、工厂或有效期。
- 单张正面图不能补造裆部剖面、显微纤维、测试结果、工厂或仓库。

## 固定四张B端详情图

每张图输出：采购商问题、决策任务、版式、可发布英文文案、证据来源、真实素材、制作提示词、禁用项、C级补料动作。

### 图1：产品五区结构与规格

回答：产品具体怎么做，和目标规格是否一致？

- 中央为真实产品全貌，周围标注腰头、裆部、腿部、袜头、袜跟/脚底；按实际结构删减，不硬凑。
- 配置规格卡：D数、成分、颜色、尺码、裆型等已确认字段。
- 每个放大窗用“部位 + 工艺/结构 + 可核验规格”，不写无证消费者收益。
- 压力袜有报告时可展示压力梯度和尺码条件。

### 图2：材质、针织工艺与质检细节

回答：材料和做工是否稳定、能否验收？

- 使用真实腿部织纹、腰头、裆部缝线、袜头/袜跟微距。
- 可加入成分、纱线规格、针数、缝线方法或公差，但必须有规格单或技术图纸。
- 工艺流程或质检点只展示真实环节，如织造、染色、定型、外观检查、尺寸检查。
- 显微纤维、针密度和剖面图不能由AI生成后冒充技术证据。

### 图3：功能测试与量化验证

回答：关键性能是否有可复核数据？

- 选择1–2项与采购风险最相关的测试：压力、回弹、耐磨、防勾丝、色牢度、透气或保暖。
- 展示测试标准、条件、样本、仪器、单位、结果和报告来源。
- 第三方报告优先于工厂自测；工厂自测须明确标注。
- 无测试数据时，本图只输出中文检测方案与所需字段，不制作英文结果卡，不生成实验室或仪器。

### 图4：OEM/ODM、品控与交付能力

回答：供应商能否按要求定制并稳定交货？

- 上半区：已确认定制矩阵——颜色、Logo位置、腰卡/吊牌、包装、尺码或结构。
- 下半区：真实流程——需求确认、打样、样品确认、大货、质检、包装、出货；按实际删改。
- 最多展示3项硬数据：MOQ、样品周期、交期、产能、质检节点或认证；全部需A级证据。
- CTA使用 `Request a Specification Review`, `Request Samples` 或 `Discuss Private Label Requirements`，前提是能力已确认。
- 工厂、仓库、包装、证书使用真实素材，不能生成后冒充。

## B端英文文案规则

- 用专业、短促、可核验的英文，避免情绪化或奢侈品式空话。
- 优先使用 `product specification`, `construction detail`, `test condition`, `customization option`, `quality checkpoint`, `lead time`。
- 不写 `perfect legs`, `must-have`, `viral`, `slimming`, `luxury feel` 等C端词。
- 不使用无证据的 `best factory`, `lowest price`, `100% defect-free`, `guaranteed delivery`, `medical grade`。
- 参数、单位和贸易术语保持原资料精度与含义。

## 视觉规范

- 技术型中性底色、清晰网格、真实微距、线稿标注和数据卡。
- 一张图解决一个采购问题；数据少而可信，不堆图标。
- 工厂和仓库照片保持真实拍摄质感，不用宏大生成场景。
- 适配移动端阅读：关键数字大于说明文字，表格不横向拥挤。

## 实际成图流程

1. 建立产品指纹、规格表和证据表。
2. 只把A级/B级内容转为英文图文；C级从提示词和成图中删除。
3. 真实产品图只做裁切、放大和排版，不改变产品本体。
4. 生成工具只可生成抽象背景、线条、无数据图标等非证明性内容。
5. 结构剖面、显微纤维、测试、认证、包装、工厂、仓库和物流必须来自真实素材。
6. 恰好输出4张独立图片，不用长图或拼图代替。
7. 发布前调用袜子图文合规检查。

## 验收标准

- 恰好4张B端图，依次覆盖结构规格、材质工艺、量化验证、定制交付。
- 每张图回答明确采购问题，并提供可追溯证据。
- 不输出C端爆品标题、穿搭情绪、显瘦或个人购买话术。
- 不虚构MOQ、OEM/ODM、测试、认证、产能、交期、工厂或仓库。
- 产品保真，技术信息准确，移动端可读。
