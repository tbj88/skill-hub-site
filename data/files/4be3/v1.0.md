# 工业品图纸-实物-场景 全链路视觉技能 v1.0

> 一句话定位：**面对工业品/交通设施/五金/机械/建筑配件类工厂客户，从「买家结构图纸」到「上架级实物+场景素材」的一站式生成技能。**

---

## 为什么需要这个技能

工厂型客户（尤其是 B2B 工业品工厂）的视觉痛点和软品类完全不同：

1. **客户往往先拿一张买家结构图纸来问「能不能做」**——需要**同款风格**的 tech pack 回复
2. **工厂只有一张平淡的产品实拍**——买家看不懂尺寸和结构，需要**图纸+实物+场景三件套**
3. **场景图最容易翻车**——普通生成的场景图**尺寸感和弧度感全丢**（这是本技能的核心避坑点）

这套技能把上述痛点固化成 **4 阶段流水线**，每一阶段都有明确的**输出规范 + 避坑铁律**。

---

## 四阶段工作流总览

```
[输入: 产品实拍图 或 买家结构图纸]
    │
    ├─ 阶段 1：买家风格 Tech Pack 结构图纸  (image_generate + complex)
    │           └─ 三视图 + 剖面 + 3D 轴测 + 工程标题栏
    │
    ├─ 阶段 2：图纸/实物 双向还原              (image_edit + auto_generation)
    │           └─ 图纸 → 实物 / 实物 → 图纸
    │
    ├─ 阶段 3：多角度实物矩阵                  (image_edit ×3)
    │           └─ 顶视 + 侧视 + 3/4 俯视 三张成套
    │
    └─ 阶段 4：B/C 端应用场景图                 (image_edit ×N)
                └─ 分 B 端 (工业/物流) + C 端 (家用/停车场) 分组出图
                └─ ⚠️ 必用「低位 3/4 侧视角 + 尺寸参照物」构图（核心避坑）
```

**触发规则**：
- 用户只说「做图」→ 询问要哪一阶段/是否全套
- 用户说「按这份图纸做实物」→ 从阶段 2 起
- 用户说「做场景图」→ 直接阶段 4（务必强调阶段 4 铁律）
- 用户说「一套图」→ 阶段 1→4 全跑

## 阶段 1：买家风格 Tech Pack 结构图纸

### 何时触发
- 客户发来一张买家的 CAD 图纸/结构图，说"帮我做一份同款风格"
- 工厂只有实物图，想主动做一份 tech pack 发给潜在买家

### 图纸必备 4 模块
1. **三视图**：Top View / Side View / Front View，带精确尺寸标注（mm）
2. **剖面图**：类似 A-A、B-B 剖切，展示内部结构（加强筋、腔体等）
3. **3D 轴测图**：等距投影，让买家看到整体形态
4. **工程标题栏**：右下角标题栏，含产品名 / 材料 / 比例 / 重量 / 图号 / 日期 / 制图人

### 生成参数（关键）
```
tool = image_generate
task_type = complex        # 必须 complex，simple 出不了工程图质感
aspect_ratio = 4:3         # 工程图纸黄金比例
resolution = 2K            # 图纸细节多，必须 2K
```

### Prompt 模板（英文，AI 更擅长工程语汇）
```
Professional engineering technical drawing / tech pack in classic mechanical
drafting style, white paper background with fine blue-grid, thin black
line-work, ISO drafting standard. Layout contains:
(1) Top View with dimension callouts in mm,
(2) Side View / Cross-section A-A showing internal reinforcement ribs,
(3) 3D isometric view at top-right,
(4) Engineering title block at bottom-right containing:
    PART NAME / MATERIAL / SCALE 1:5 / WEIGHT / DRAWN BY / DATE / DWG-NO.
All dimension arrows, extension lines, hatching, and part callouts follow
ISO 128 standard. Product: <此处填产品品类+关键尺寸+材质>.
Ultra-crisp black lines on white, no shadows, no color fills.
```

### 中英文切换
若客户要求中文图纸，把 prompt 里所有英文字段改中文：
- Top View → 顶视图
- Side View → 侧视图
- Cross-section A-A → 剖面 A-A
- Engineering title block → 工程标题栏
- Part Name / Material / Scale / Weight / Drawn By / Date → 产品名 / 材料 / 比例 / 重量 / 制图人 / 日期

### 合规性附加分析（可选加分项）
针对交通设施/工业品类，图纸生成后附一段**合规性分析**：
- **美国**：MUTCD（交通控制设施手册）
- **欧洲**：CE-CPR（建筑产品法规）、REACH、RoHS
- **澳新**：AS 1428.1（无障碍标准）
- **通用**：ASTM C1028 防滑测试 / UV 抗老化 / 承重疲劳测试
- **标签要求**：模刻承重警告 + 材质标识 + 原产地

## 阶段 2：图纸/实物双向还原

### 场景 A：图纸 → 实物
客户已有 tech pack，想看看实物长啥样。

```
tool = image_edit
task_type = auto_generation
reference_images = [tech_pack_url]
preserve_product = false      # 需要 AI 自由发挥形态
aspect_ratio = 1:1
resolution = 2K

prompt:
Photorealistic industrial product photograph based on the reference tech
drawing. Convert the 2D engineering blueprint into a real 3D physical
product with authentic material texture (industrial rubber / zinc alloy /
steel / engineering plastic — pick per drawing spec). Match ALL dimensions,
angles, and structural features from the drawing exactly: <关键结构描述,
如 "18-degree arc top, diamond anti-slip grid pattern, mounting holes,
10cm thick wedge profile">. Studio lighting, matte industrial finish,
neutral gray background, 45-degree overhead angle.
```

### 场景 B：实物 → 图纸
工厂只有产品实拍，想生成买家风格 tech pack。

- 用**阶段 1** 的 prompt 模板
- 但把 `image_generate` 换成 `image_edit`
- `reference_images = [实物图_url]`
- 在 prompt 开头加：`Based on the reference product photo, redraw as a professional engineering technical drawing...`

## 阶段 3：多角度实物矩阵（必出 3 张）

工业品实物矩阵**固定 3 张**（不是软品类的 6 张），因为工业品形态相对单一，3 个关键角度足够：

| 图号 | 视角 | 用途 | Prompt 关键词 |
|---|---|---|---|
| 3-1 | **Top View** 顶视 | 展示防滑纹/表面结构/安装孔位 | `strict top-down orthographic view, camera directly above` |
| 3-2 | **Side Profile** 侧视 | 展示厚度/坡度/剖面轮廓 | `pure side profile at eye-level, product silhouette clearly visible` |
| 3-3 | **3/4 Overhead** 高角度俯视 | 主展示图，兼顾整体感和细节 | `high-angle 3/4 perspective, 30-degree elevation, showcase product` |

### 统一风格锁定（必须逐张加入 prompt）
```
Industrial photography style, matte black/gray asphalt background,
studio softbox lighting, no shadows on background, product occupies
70% of frame, ultra-crisp texture detail on rubber surface, sharp focus.
```

### 生成参数
```
tool = image_edit
task_type = auto_generation
reference_images = [产品实拍_url]
preserve_product = true       # 关键！保留产品原形态
aspect_ratio = 1:1
resolution = 2K
output_count = 3              # 告诉主 Agent 需要 3 张
```

## 阶段 4：B/C 端应用场景图（⚠️ 核心避坑区）

**这是本技能最容易翻车的阶段**。血泪教训见 §避坑铁律。

### 场景矩阵（按客群分 B/C 端）

| 客群 | 场景 | 用途 |
|---|---|---|
| **B 端** | 停车场/仓库/物流门槛/工地 | 面向 B2B 采购商 |
| **B 端** | 商业建筑入口（无障碍通行） | 面向市政/工程采购 |
| **C 端** | 家用车库/私人车道 | 面向亚马逊/独立站 C 端消费者 |
| **C 端** | 无障碍/婴儿车/轮椅通行 | 面向 DTC/人文诉求 |

推荐**每类客群出 1 张**，共 2-4 张。

### ⚠️ 阶段 4 铁律（v1.0 血泪教训）

**普通场景图翻车模式**：AI 默认画高机位远景 → 产品被拍成一小块 → **尺寸感和弧度感全丢**，买家看不出这产品到底多高、坡多陡、有多大。

**唯一正确构图 = 低位 3/4 侧视角 + 尺寸参照物**：

```
prompt 必须包含以下 4 个要素（缺一不可）：

1. 【机位】low-angle 3/4 side view, camera at wheel-height (≈30cm above ground)
2. 【尺寸参照物】product placed adjacent to a REAL scale reference object:
   - 车用场景 → car tire / SUV wheel (直径约 60cm，天然尺寸参照)
   - 家用场景 → step / curb / doorway threshold (台阶天然高度参照)
   - 仓库场景 → pallet jack wheel / worker's foot
   - 建筑场景 → 15cm brick / concrete step
3. 【弧度展示】cross-section clearly visible from side, wedge profile
   and arc curvature must be sharp against neutral background
4. 【产品占比】product occupies 40-50% of frame width, reference object
   occupies another 20-30%, so the size relationship is immediately readable
```

### 阶段 4 完整 Prompt 模板
```
Photorealistic outdoor scene photograph. LOW-ANGLE 3/4 SIDE VIEW from
approximately 30cm above ground level, camera tilted 15 degrees downward.

Product: <产品描述，如 "black industrial rubber curb ramp, 100cm long,
25cm wide, 10cm tall wedge shape with 18-degree arc, diamond anti-slip
grid on top surface">.

Scene: <场景，如 "residential garage entrance with concrete driveway">.

SCALE REFERENCE (mandatory): <参照物，如 "SUV rear wheel touching the top
of the ramp, tire diameter approximately 65cm, providing clear size
comparison">.

Composition: Product wedge profile clearly silhouetted against background,
10cm thickness immediately obvious, 18-degree arc curvature sharp and
readable. Product occupies left-center of frame, reference object on right.
Natural daylight, no harsh shadows, neutral realistic color grading.
NO overhead shots, NO wide-angle distortion, NO decorative props.
```

### 生成参数
```
tool = image_edit
task_type = auto_generation      # 场景图不要用 simple（会失去场景感）
reference_images = [产品实拍_url]  # 或阶段 3 的 3/4 视角实物图作参考
preserve_product = true
aspect_ratio = 4:3               # 场景图 4:3 比 1:1 更能表达纵深
resolution = 2K
```

### 主公经验加持（v1.0 沉淀）
> 主公原话：**"尺寸大小，还有产品的弧度都没有体现出来，请更加专业一点"**
>
> 教训：初版场景图翻车的两个信号——① 找不到尺寸参照物 ② 侧面弧度看不清。
> 出图后**必须逐张 read 自检**：能不能一眼看出产品有多高、坡多陡？看不出立即重跑。

## 触发流程 SOP（Agent 执行步骤）

1. **识别输入类型**：
   - 输入=结构图纸 → 直接问客户"是想还原成实物图，还是需要中英文互转图纸？"
   - 输入=产品实拍 → 直接问"要跑全套 4 阶段，还是只做某几个阶段？"
   - 输入=产品名/链接 → 先用 `product_supplier_search` 或让客户补图

2. **确认关键参数**（一次问齐，不要拆开问）：
   - 产品品类（决定材质渲染方向：橡胶 / 锌合金 / 钢 / 工程塑料）
   - 目标市场（决定合规提示模块）
   - 图纸语言（中/英）
   - 场景客群（B/C/两者）

3. **按阶段执行**，每阶段完成后 `read` 自检产物：
   - 阶段 1 自检：三视图 + 剖面 + 3D + 标题栏 四要素齐全？
   - 阶段 2 自检：还原图和图纸的关键结构一致？
   - 阶段 3 自检：3 个视角互相区分明显？
   - 阶段 4 自检（**最严**）：能一眼看出产品尺寸和弧度？

4. **归档 + 交付**：
   - 用 `bash mkdir -p` 建目录
   - 用 `bash cp` 或 `curl` 把生成的图 URL 下到本地
   - 输出 `present_files` 展示所有成品

## 反面示例（禁止行为）

- ❌ 阶段 4 用高机位远景 → 尺寸感全丢
- ❌ 阶段 4 不加尺寸参照物 → 买家不知道多大
- ❌ 阶段 1 用 `task_type=simple` → 出不了工程图质感
- ❌ 阶段 3 只出 1-2 张 → 视角覆盖不全
- ❌ 阶段 2 图纸→实物时 `preserve_product=true` → AI 不敢自由发挥形态
- ❌ 场景图里堆满装饰道具（花盆/绿植/招牌）→ 分散注意力，反显不专业
- ❌ 出图后不 read 自检 → 带病交付

## 适用行业清单

**主打**：
- 交通设施（减速带、路沿坡、路桩、防撞条、路障、反光标）
- 市政橡胶件（井盖垫、缓冲块、桥梁支座）

**兼容**：
- 五金配件（挂钩、锁具、把手、门吸）
- 机械零件（法兰、齿轮、轴承座）
- 建筑塑料件（管件、扣件、模板夹具）
- 锌合金/铜制品（水龙头、阀门、装饰件）
- 工业耗材（密封件、垫圈、O 型圈）

**不适用**（请走其他技能）：
- 服装/丝袜/日用品 → 《长筒丝袜》/《汤 主图附图》
- 户外软装（垫子/伞/家居） → 《爱以思 主图详情专家》
- 电子产品/消费电子 → 需另建技能
